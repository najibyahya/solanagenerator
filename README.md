# SOLANA Wallet Generator
![image](https://github.com/user-attachments/assets/d8f4f580-3ad8-4674-a530-be31779fb993)

## Description
This script generates a Solana wallet randomly. Every wallet
have a secure address and private key. Data wallet will
saved in the wallet.txt file and only the Address is saved
in the address.txt file.

## Tools
- Nodejs v22.xxx

## How to Install & Run
```bash
git clone https://github.com/najibyahya/solanagenerator.git
```
```bash
cd solanagenerator
```
```bash
npm install
```
```bash
node index
```
```bash
enter the number of wallets to create
```
